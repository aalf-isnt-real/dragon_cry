## Domain Casting

Select 2 domains to start with, you will learn the spells associated to those domains
When gaining a spell slot, select which domain you add that slot to
Can change slot allocation while Resting
Gain one spell from each domain on lvUP

## Domains
Life, Death, Nature, Sky, Ocean, Mind, Destruction
